# Pit Crew owner UI

Server-rendered help-desk operations for the configured Plex administrators.
The engine and intake databases are read-only sources; the admin database owns
sessions and an append-only command audit. The UI does not contact media services.

The visual system extends the viewer pages: warm forest neutrals, pale green
links and controls, system typography, clear focus rings and dark mode by default.
Queue rows lead to evidence and journal detail; native forms work without JavaScript.
Navigation wraps on tablets and narrow screens. Every control has a label and
44-pixel touch target. Unknown, stale and unavailable observations stay explicit.
